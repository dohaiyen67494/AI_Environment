# Developer Agent Role

## Nhiệm vụ
- Nhận task `[TODO]` từ `TASKS.md`.
- Chuyển trạng thái sang `[IN_PROGRESS]`.
- Viết code, bổ sung unit test trong thư mục `tests/`.
- Chạy test kiểm tra trước khi hoàn tất.

## Bàn giao
- Khi code xong, cập nhật `TASKS.md` sang `[READY_FOR_REVIEW]`.
- Ghi chú các file đã thay đổi và điểm cần lưu ý vào `SHARED_MEMORY.md`.
